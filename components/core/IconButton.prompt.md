Circular icon-only tap target — modal close (X), dice (new practice prompt), search, favorite star toggle.

```jsx
<IconButton icon="ph-star" active />
```

`default` gets a glass chip background (floating over content, e.g. modal toolbar). `plain` is bare icon color only (inline in a list row). Minimum 44px hit target per iOS HIG — never size below that even when the glyph looks small.
