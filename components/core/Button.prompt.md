Button is the single action primitive for every CTA in the app — "Begin", "Save to Journal", "Done", "Answer again".

```jsx
<Button variant="primary" icon="ph-check">Save to Journal</Button>
```

`primary` = solid accent, used for the one dominant action per screen. `secondary` = glass outline, for a paired lesser action ("Answer again" next to a completed daily card). `ghost` = text-only, toolbar-adjacent actions. `danger` = destructive (journal delete confirmation).
